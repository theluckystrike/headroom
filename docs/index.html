What it does

Counts agents, not processes

One Claude Code session is a node process plus MCP servers, language servers and shells. Headroom folds each tree into one agent and measures its real memory footprint.

Counts every terminal

One session is one tty: a tab, a split, a tmux pane. Terminal, iTerm2, Ghostty, WezTerm, kitty, Alacritty, Warp, VS Code, Cursor and Zed all count the same way.

Answers one question

Can I start one more? The number on the right is how many more agents fit before the Mac starts swapping hard. It reads tight at 3 or fewer and danger at 0.

The math

# what Activity Monitor calls free
available = total - (app memory + wired + compressed)

# what one more agent will cost: mean physical footprint
# of the running agent process trees, MCP servers included
per_agent = clamp(mean(agent trees), 150M, 4G)   # 600M if none run

headroom  = floor((available - reserve) / per_agent)   # reserve 3G, 6G under pressure

# danger when any of these hold
danger    = headroom == 0  or  pressure == critical  or  (swap ≥ 85% and disk < 10G)

Measured on the author's 36 GB Mac: 29.1G used (11.6G apps + 3.7G wired + 13.8G compressed), 6.9G available, warning pressure so a 6G reserve, 37 agents at 249M each: 3 more fit. Minutes later: 0.
